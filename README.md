## ⚡ Stack Tecnológico ("Cyber-Industrial Data Lab")

- **Frontend & Framework:** [Next.js 16](https://nextjs.org/) (App Router) + [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Diseño & UI:** [Tailwind CSS v4](https://tailwindcss.com/) (Dark Mode `bg-slate-950`, acentos cian petrolero, esmeralda y rojo carmesí)
- **Visualización & Gráficos:** [Recharts](https://recharts.org/) (Radar de Competencias 5D) + [Framer Motion](https://www.framer.com/motion/) (Animaciones fluidas)
- **Iconos:** [Lucide React](https://lucide.dev/)
- **Base de Datos & Backend:** [Supabase](https://supabase.com/) (`@supabase/supabase-js`) con persistencia en tiempo real y fallback automático a `localStorage` para garantizar 100% de disponibilidad.
- **Motor de Evaluación con IA:** [Google Gemini API](https://ai.google.dev/) (`@google/generative-ai` con `gemini-2.0-flash` y visión multimodal).

## 🚀 Despliegue en Producción (Vercel)

El proyecto está 100% listo para desplegar en [Vercel](https://vercel.com):

1. Clona el repositorio:
   ```bash
   git clone https://github.com/JChaconMoncada/Avanzando-en-el-ML.git
   cd Avanzando-en-el-ML
   npm install
   ```
2. Configura las variables de entorno en Vercel o en tu `.env.local`:
   ```env
   NEXT_PUBLIC_SUPABASE_URL=https://nlmwwulivnbjnytoxcjv.supabase.co
   NEXT_PUBLIC_SUPABASE_ANON_KEY=sb_publishable_...
   NEXT_PUBLIC_GEMINI_API_KEY=AQ.Ab8...
   ```
3. Ejecuta la compilación de producción:
   ```bash
   npm run build
   npm run start
   ```
